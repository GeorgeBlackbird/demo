# Оптимальный стек и план реализации (2-3 часа)

## Почему именно этот стек

Для ограничения в **2-3 часа** оптимален стек, где:
- быстро поднять интерфейс и CRUD без сложной инфраструктуры;
- просто читать Excel;
- можно собрать под Windows в `.exe` с минимальными усилиями.

**Выбор:** `Python 3.11 + PyQt5 + SQLite + pandas/openpyxl + PyInstaller`

### Обоснование выбора
- **PyQt5**: самый быстрый путь к desktop UI с таблицами, формами, ролями и условной стилизацией.
- **SQLite**: нулевая настройка БД, полноценные внешние ключи и ограничения для 3НФ.
- **pandas/openpyxl**: импорт Excel в 5-10 строк на таблицу, высокая скорость реализации.
- **PyInstaller**: стандартная сборка Python-приложения в единый `.exe` для Windows.

## Минимальная архитектура (чтобы успеть)

- `main.py` — точка входа, переключение окон.
- `db.py` — создание БД, подключение, SQL-запросы.
- `import_excel.py` — разовый импорт данных из Excel.
- `auth.py` — вход и получение роли/ФИО.
- `catalog_window.py` — каталог, поиск/фильтр/сортировка, стилизация.
- `admin_windows.py` — формы CRUD товаров и заказов.
- `schema.sql` — DDL в 3НФ (PK/FK/ограничения).

## SQL-модель в 3НФ (минимальный набор таблиц)

- `roles(role_id, role_name)`
- `users(user_id, role_id, full_name, login, password_hash)`
- `categories(category_id, category_name)`
- `manufacturers(manufacturer_id, manufacturer_name)`
- `suppliers(supplier_id, supplier_name)`
- `products(product_id, article, name, description, category_id, manufacturer_id, supplier_id, price, discount_percent, stock_qty, image_path)`
- `pickup_points(point_id, point_name, address)`
- `order_statuses(status_id, status_name)`
- `orders(order_id, user_id, point_id, status_id, created_at, delivery_date)`
- `order_items(order_item_id, order_id, product_id, qty, price_at_order, discount_at_order)`

Критичные ограничения:
- FK включены (`PRAGMA foreign_keys = ON`).
- `CHECK (price >= 0)`, `CHECK (stock_qty >= 0)`, `CHECK (discount_percent BETWEEN 0 AND 100)`.
- Запрет удаления товара, если есть в `order_items` (через FK `ON DELETE RESTRICT`).

## Роли и права (ровно под ТЗ)

- **Гость**: просмотр каталога без поиска/фильтрации.
- **Клиент**: просмотр каталога.
- **Менеджер**: просмотр + поиск/фильтр + работа с заказами.
- **Администратор**: полный CRUD товаров и заказов.

В верхнем правом углу после входа: `ФИО | Роль`.

## UI-решение (быстро и в рамках style guide)

- Шрифт приложения: **Times New Roman** (глобально через стиль Qt).
- Цвета:
  - фон: `#FFFFFF`
  - доп.фон: `#7FFF00`
  - кнопки действий: `#00FA9A`
- Условное форматирование:
  - скидка > 15% -> фон карточки/строки `#2E8B57`;
  - нет на складе -> голубая подсветка строки;
  - старая цена красная и зачеркнутая, новая черная.

## 2:30-2:45 — блок-схема и упаковка
- Быстро собрать блок-схему авторизации по ГОСТ 19.701-90, экспорт в PDF.

## Команды для сверхбыстрого старта

```bash
python -m venv .venv
.venv\Scripts\activate
pip install pyqt5 pandas openpyxl pyinstaller
pyinstaller --onefile --windowed main.py
```

## Риски и как снизить их за 2-3 часа

- **Риск:** не успеть красивый UI.  
  **Решение:** использовать `QTableWidget/QTableView` и stylesheet вместо сложных кастомных карточек.

- **Риск:** проблемы с `.exe`.  
  **Решение:** собрать минимум за 20-30 минут до дедлайна и проверить запуск на чистом пути.

- **Риск:** ошибки импорта Excel.  
  **Решение:** заложить явное логирование строк с ошибками и не падать на одной записи.
